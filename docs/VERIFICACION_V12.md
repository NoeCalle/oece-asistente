# Verificación de la versión 1.2

01/11/2026. Corte normativo conservado: **31/10/2026**. La entrega añade contraste financiero sobre hechos citados; no extiende vigencias ni acredita aceptación institucional.

## Software y trazabilidad

131 pruebas: las 109 anteriores y 22 nuevas. Incluyen límites exactos R2/R3/R8, el tercio sin error de redondeo, patrimonio/utilidad negativos, denominadores cero, datos ausentes, cifras no finitas/exponentes extremos, estado financiero futuro, bases mezcladas, datos SBS, ramas excluidas, OCR sin cotejo, ventana temporal y contradicción entre declaración y cálculo.

El panel se reinició sin trabajos activos y se repitió en Edge la creación, ficha, booleanos, carga, procesamiento y descarga Word, sin errores JavaScript observados. Se reutilizó el guion de interfaz de 1.1 sobre el proceso actualizado.

Dos expedientes ficticios recorren lectura, hechos, matriz, Word, originales y manifiesto. El nuevo registro financiero se conserva como dependencia de cada revisión. El verificador de biblioteca ahora coteja también las referencias de los tres motores: consultores, procedimientos y finanzas, contra nombre, URL, hash y página de los originales manifestados. Eso verifica procedencia, no vigencia jurídica.

## Ejemplos Word

Dos ejemplos sintéticos de actualización financiera, cinco páginas cada uno. Uno satisface los tres umbrales aritméticos y mantiene pendiente el análisis integral. El otro declara solvencia pero sus importes no satisfacen R2/R8: el control agregado solicita aclaración y no mantiene el cumplimiento declarado. Ambos incluyen un indicador referencial negativo sin convertirlo en rechazo automático.

Las diez páginas finales se renderizaron con el circuito LibreOffice local usado en 1.1 y se inspeccionaron íntegramente. No se observaron texto cortado, tablas fuera de página ni superposiciones. El formato sigue siendo provisional. Los cinco ejemplos y 19 páginas de 1.1 permanecen como evidencia histórica de esa versión, no se presentan como nuevos renders 1.2.
