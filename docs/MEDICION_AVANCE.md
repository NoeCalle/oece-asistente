# Cómo se estima el avance

Actualización 31/10/2026: alrededor de **60 % del plan amplio** (rango 55–65 %). Es juicio de planificación por entregables, no precisión, horas ni garantía de aptitud institucional. La versión asistida puede usarse aunque el plan amplio siga abierto.

| Fase | Peso | Avance estimado de fase | Aporte |
|---|---:|---:|---:|
| Plan | 5 % | 100 % | 5 |
| Biblioteca | 20 % | 65 % | 13 |
| Procedimientos | 20 % | 50 % | 10 |
| Base técnica | 25 % | 75 % | 18,75 |
| Piloto | 20 % | 60 % | 12 |
| Validación y expansión | 10 % | 15 % | 1,5 |
| Total | 100 % | | 60,25, redondeado a 60 |

El incremento desde 35 % se apoya en código nuevo de operación, panel verificado en navegador, vigilancia/memoria, motor documental de consultores con diez situaciones ejecutadas, OCR real acotado, biblioteca unificada y 87 pruebas. No se gana avance jurídico por contar tests. [Evidencias y límites](VERIFICACION_V1.md).

Se mantienen pendientes las excepciones y cadena normativa, evaluadores sustantivos de otros módulos, aceptación funcional/institucional y casos reales autorizados. La QA visual completa del Word v1 también sigue abierta porque la exportación se bloqueó. Los modelos reales de informes se adaptarán cuando el usuario disponga de ellos.
