# Cómo se estima el avance
Actualización: 30/10/2026. **Estimación global: alrededor de 25 %**, con rango orientativo 20–30 %. Es una referencia de planificación basada en entregables comprobados; no mide horas ni porcentaje de funciones operativas.

| Fase | Peso en proyecto | Avance estimado de fase | Aporte al total |
|---|---:|---:|---:|
| Plan y organización | 5 % | 100 % | 5 puntos |
| Biblioteca normativa | 20 % | 50 % | 10 puntos |
| Procedimientos y reglas | 20 % | 25 % | 5 puntos |
| Base técnica | 25 % | 20 % | 5 puntos |
| Piloto completo e informe Word | 20 % | 0 % | 0 puntos |
| Validación y expansión | 10 % | 0 % | 0 puntos |
| **Total** | **100 %** | | **25 puntos** |

Los pesos y la valoración parcial se fijan por juicio de planificación. No son una medición objetiva de esfuerzo ni una predicción del plazo restante. La incertidumbre se expresa con un rango, no con decimales adicionales.

## Evidencia y criterio
La organización inicial está guardada. La biblioteca dispone de catálogo, originales y búsqueda, pero falta su cierre jurídico. Solo el primer procedimiento tiene una matriz candidata. La base técnica lee y busca documentos y tiene una muestra OCR, pero el coordinador y el procesamiento de expedientes siguen pendientes. El piloto con Word y los demás módulos aún no funcionan.
No se asigna avance del piloto completo por haber escrito su ficha o sus pruebas futuras: esa preparación se cuenta en procedimientos.

## Cómo actualizar
Cambiar una fase únicamente cuando exista evidencia nueva y verificable; enlazar commit, archivo o ejecución. Terminar una herramienta parcial no permite cerrar una fase amplia. Revisar el peso si cambia el alcance del proyecto y explicar el cambio, sin comparar porcentajes como si el alcance fuera idéntico.
El control OCR de cuatro regiones mantiene la estimación global alrededor de 25 %: mejora una parte de la base técnica, sin cerrar el flujo del agente.
