# Cómo se estima el avance

Actualización 01/11/2026: **75 % del plan amplio** (rango orientativo 70–80 %). Es juicio de planificación por entregables, no horas, precisión jurídica ni aptitud institucional.

| Fase | Peso | Avance estimado de fase | Aporte |
|---|---:|---:|---:|
| Plan | 5 % | 100 % | 5 |
| Biblioteca | 20 % | 70 % | 14 |
| Procedimientos | 20 % | 70 % | 14 |
| Base técnica | 25 % | 85 % | 21,25 |
| Piloto | 20 % | 85 % | 17 |
| Validación y expansión | 10 % | 40 % | 4 |
| Total | 100 % | | 75,25, redondeado a 75 |

El aumento desde 60 % se fundamenta en controles propios para cuatro procedimientos, propuestas CMC/plazos con fuentes, flujo de navegador actualizado y cierre de QA visual de cinco Word sintéticos (19 páginas). Las 109 pruebas dan evidencia de comportamiento de software; contarlas no demuestra validez jurídica general. [Verificación](VERIFICACION_V11.md).

No se cierran excepciones y cadena normativa, automatización sustantiva completa, aceptación funcional/institucional, modelos reales ni casos laborales autorizados. La interpretación desde el asistente elegido es el alcance confirmado por el usuario; integrar un modelo autónomo al panel no es un pendiente de este alcance. La ventana normativa de los cuatro módulos nuevos se conserva al 31/10/2026. [Datos](../proyecto/avance.json) y [estado](ESTADO.md).

La versión 1.2 añade contraste financiero y 22 pruebas; el total es 131. Se conserva la estimación en 75 %: no hay nueva aceptación funcional/institucional ni cierre de cadena normativa. [Evidencia financiera](VERIFICACION_V12.md).

La versión 1.3 añade portabilidad del cliente de IA y 23 pruebas (154 totales). Se mantiene 75 %: el protocolo local no equivale a una validación con otro modelo, casos laborales o cierre normativo. [Evidencia](VERIFICACION_PORTABILIDAD.md).

La versión 1.4 agrega recuperación de quince fichas TUPA y corrige una carrera de publicación de entregas; 169 pruebas. Se mantiene la estimación 75 %: el índice por fichas es avance parcial de T20 y no una consolidación jurídica por disposición. [Evidencia](VERIFICACION_V14.md).
